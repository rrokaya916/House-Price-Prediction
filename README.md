# House Price Prediction

## Project Overview

A Python-based machine learning project that analyzes housing data and predicts house prices using regression models.

## Features

* Exploratory Data Analysis (EDA)
* Data preprocessing and handling missing values
* Feature scaling and categorical encoding
* Training and comparing regression models
* Model evaluation using MAE, MSE, RMSE, and R²
* House price prediction from CSV files
* Tkinter graphical user interface for predictions
* Exporting prediction results to CSV

## Machine Learning Models

* Linear Regression
* Random Forest Regressor
* XGBoost Regressor

## Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Matplotlib
* Seaborn
* Tkinter
* Joblib

## Project Structure

| File                | Description                                                            |
| ------------------- | ---------------------------------------------------------------------- |
| `Eda.py`            | Performs exploratory data analysis and generates visualizations.       |
| `preprocessing.py`  | Prepares the dataset and processes numerical and categorical features. |
| `train_models.py`   | Trains and evaluates regression models.                                |
| `prediction.py`     | Generates house price predictions.                                     |
| `gui_prediction.py` | Provides a graphical interface for predictions.                        |
| `kc_house_data.csv` | The housing dataset used by the project.                               |
| `requirements.txt`  | Lists the required Python packages.                                    |

## Installation

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Install the required packages:

```bash
python -m pip install -r requirements.txt
```

## How to Run

Run the scripts in the following order.

### Step 1: Data Preprocessing

```bash
python preprocessing.py
```

### Step 2: Train the Models

```bash
python train_models.py
```

### Step 3: Make Predictions

```bash
python prediction.py
```

To use the graphical interface:

```bash
python gui_prediction.py
```

## Dataset

The project uses the `kc_house_data.csv` housing dataset.

## Notes

* Run preprocessing before training the models.
* Train the models before running the prediction scripts.
* The prediction scripts require the saved preprocessor and trained model generated by the earlier steps.
* Model performance depends on the dataset and the selected model.
