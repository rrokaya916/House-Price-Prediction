# House Price Prediction

## Project Overview

A Python-based machine learning project for analyzing housing data and predicting house prices.

## Project Features

* Exploratory Data Analysis (EDA)
* Data preprocessing and feature scaling
* Training and comparing multiple regression models
* Model evaluation using MAE, MSE, RMSE, and R²
* House price prediction from CSV files
* Tkinter graphical user interface for running predictions
* Saving prediction results to a CSV file

## Machine Learning Models

* Linear Regression
* Random Forest Regressor
* XGBoost Regressor

## Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Matplotlib
* Seaborn
* Tkinter
* Joblib

## Project Files

* `Eda.py`: Exploratory data analysis and visualizations.
* `preprocessing.py`: Data preprocessing and dataset splitting.
* `train_models.py`: Model training, evaluation, and best-model selection.
* `prediction.py`: Prediction from CSV files and a manual example.
* `gui_prediction.py`: Graphical interface for CSV-based predictions.

## Dataset

The project uses the `kc_house_data.csv` housing dataset.

## Notes

The saved model and preprocessor files must be generated by running the preprocessing and training scripts before using the prediction scripts.

The exact execution order and required dependencies should be confirmed before running the project.
